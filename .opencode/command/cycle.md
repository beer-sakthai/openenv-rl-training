Read the cycle-workflow skill (`.opencode/skills/cycle-workflow/SKILL.md`).

## Stage 1: 🎯 Dream
Determine what the user needs. Ask clarifying questions if needed. State the objective.

## Stage 2: 🏗️ Hope
Check current state. List files to change. Order of operations. Verify tools available.

## Stage 3: ❤️ Care
Execute each change. One at a time. Verify after each.

## Stage 4: 🎉 Joy
Commit. Push. Deploy. Upload.

## Stage 5: 🔐 Trust
Verify everything landed correctly. Check status.

## Stage 6: 🌱 Growth
Save lessons learned. Patch any skill gaps. Update AGENTS.md if needed.

Return the result of each stage as you complete it.
